Agentes de Desenvolvimento e Responsabilidades

Para construir o portfólio "Lucas Physique" em Angular com qualidade premium, o projeto precisará da atuação dos seguintes "agentes" (que podem ser interpretados como papéis assumidos por você ou por IAs assistentes durante o processo):

1. Agente de UX/UI Design (O Estrategista Visual)

Objetivo: Traduzir a identidade "Premium/Elite" (Preto e Verde Neon) para a interface.

Responsabilidades:

Definir a paleta de cores exata (códigos HEX) e a tipografia (ex: fontes sem serifa, arrojadas, como Montserrat ou Teko para títulos).

Desenhar a estrutura de alto contraste para destacar a tabela de preços.

Garantir que a usabilidade móvel (Mobile UX) seja impecável, visto que a maioria dos clientes acessará via Instagram/Celular.

2. Agente Desenvolvedor Angular (O Engenheiro Front-end)

Objetivo: Transformar o design e as especificações em código funcional.

Responsabilidades:

Inicializar o projeto Angular (ng new lucas-physique-portfolio).

Criar a arquitetura de componentes (ng generate component ...).

Implementar estilos usando SCSS, isolando as variáveis de cor (ex: $neon-green, $bg-dark).

Garantir a responsividade usando CSS Grid/Flexbox.

Otimizar o build da aplicação para produção.

3. Agente Copywriter / Marqueteiro (O Vendedor)

Objetivo: Refinar os textos para maximizar a conversão.

Responsabilidades:

Adaptar a biografia longa fornecida para blocos de texto dinâmicos e fáceis de ler na web (uso de bullet points e negritos).

Criar chamadas persuasivas (CTAs) em todas as seções.

Garantir que a ênfase na economia dos planos longos (especialmente o Anual) fique clara e atrativa para o usuário.

4. Agente de QA (Quality Assurance)

Objetivo: Testar a aplicação antes do lançamento.

Responsabilidades:

Verificar se todos os textos e preços conferem exatamente com o SPEC.md.

Testar a visualização em diferentes tamanhos de tela (Desktop, Tablet, Smartphone).

Garantir que os links de contato (WhatsApp/Checkout) estão redirecionando corretamente.
